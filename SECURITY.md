# Security

This project is research-only. It does not execute orders, and its output is not a trading instruction.

Report suspected vulnerabilities privately through this repository's GitHub private vulnerability reporting. Do not include resolved endpoints or other secrets in a public issue. If an endpoint may have been exposed, rotate it before further investigation.

Never commit `.env` files, webhook values, databases, runtime data, reports, Pine source, or resolved endpoints.
