# Indicator boundary

This directory intentionally contains no formulas. Every source-aligned plugin remains unavailable until pinned TradingView point-in-time expected-output vectors exist and an independent implementation matches them.

The deferred candidates trace to LuxAlgo's [Smart Money Concepts](https://tw.tradingview.com/script/CnB3fSph-Smart-Money-Concepts-SMC-LuxAlgo/) and [ICT Concepts](https://tw.tradingview.com/script/ib4uqBJx-ICT-Concepts-LuxAlgo/) indicators. Both pinned sources declare CC BY-NC-SA 4.0. Any adapted material must preserve attribution, noncommercial use, and ShareAlike terms. See `provenance/sources.yaml` and `LICENSES/README.md`.

No Pine source is vendored here. The indicators are not strategies, and these registrations make no claim of formula equivalence, profitability, entries, exits, sizing, or costs.
