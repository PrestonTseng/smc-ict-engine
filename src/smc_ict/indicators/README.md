# Indicator boundary

This directory contains the seven active deterministic Python plugins. They evaluate only completed role candles and declared observations; no Pine runtime, visual object, alert, or provider branch is present.

Six plugins trace to pinned revisions of LuxAlgo's [Smart Money Concepts](https://tw.tradingview.com/script/CnB3fSph-Smart-Money-Concepts-SMC-LuxAlgo/) and [ICT Concepts](https://tw.tradingview.com/script/ib4uqBJx-ICT-Concepts-LuxAlgo/) indicators; the risk-level plugin is strategy-owned composition. Both pinned external sources declare CC BY-NC-SA 4.0. Any adapted material must preserve attribution, noncommercial use, and ShareAlike terms. See `provenance/sources.yaml`, `docs/formula-provenance.md`, and `LICENSES/README.md`.

No Pine source is vendored here. The indicators are not strategies, and these registrations make no claim of formula equivalence, profitability, entries, exits, sizing, or costs.
